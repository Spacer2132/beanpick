# 11단계 구현 범위와 금지선

11단계는 사람이 확인한 맛정보를 수동으로 덮어쓰는 단계가 아니다. 명시 원문이 확인된 자동 경로 세 개만 고친다.

첫째, 502커피로스터스의 정규화 사전에 로즈, 엘더플라워, 피치, 망고스틴을 좁게 추가한다. 둘째, 커피리브레 본문 파서가 `Cupping Note |` 형태의 명시 라벨을 읽게 한다. 셋째, 테라로사 공식몰 상세 이미지 URL이 기존 OCR 입력까지 도달하게 한다.

모모스·센터커피·헬카페 일부는 명시 원문이 없다. 묶음 상품과 인스턴트 상품은 제외 검토 대상이다. 판매 종료 상품과 기업회원 차단 상품도 파서 확장으로 해결하지 않는다.

게시 가드와 시간 제한은 약화하거나 제거하지 않는다. 구현 뒤에는 맛정보 테스트와 안전 가드를 실행하고, 실제 게시 스냅샷에서 정상 노트가 늘고 기존 노트가 소실되지 않는지 다시 확인해야 한다.
