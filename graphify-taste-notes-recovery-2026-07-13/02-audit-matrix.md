# P2와 P3 감사 분류

P2 SmartStore 21개는 기존 복구 7개, 새 명시 이미지 노트 3개, 네이버 IP 차단 10개, 상품 제외 검토 1개로 끝났다. 감사 JSON과 체크리스트에는 ID 중복과 누락이 없고, 확인된 10개 맛정보는 실제 normalizeTastingNotes 결과와 일치한다.

P3 공식몰·직영몰 15개는 이미 복구 1개, 정규화 사전 공백 1개, 본문 파서 공백 1개, 상세 이미지 획득 공백 2개, 명시 원문 없음 5개, 상품 제외 검토 3개, 판매 종료 1개, 접근 차단 1개다.

정규화 공백은 coffee502-182다. 상세 본문의 명시 노트 `로즈, 엘더플라워, 피치, 망고스틴`은 현재 빈 배열로 정규화된다.

본문 파서 공백은 coffeelibre-3176다. 상세 본문의 `Cupping Note | 조청, 메이플시럽, 밀크 초콜릿, 크리미 바디`는 명시 라벨인데 현재 본문 파서가 읽지 못한다. 기대 정규화 값은 밀크초콜릿, 메이플시럽, 조청, 크리미다.

이미지 획득 공백은 terarosa-100448과 terarosa-100019다. 감사에서 확인한 상세 이미지를 OCR에 직접 넣으면 기존 정규화가 동작한다. 따라서 OCR 또는 맛 추론 문제가 아니라 상세 이미지 URL을 수집 경로에서 전달하지 못하는 문제다.

P3 최종 검증은 15개 고유 ID, 체크리스트 15행 중 14개 확인, 접근 차단 hellcafe-60 1개 미확인으로 맞았다. 부정·제외 분류의 31개 고유 이미지 URL은 중복 없이 모두 HTTP 접근 가능했다.
